About

This dashboard reads from GET /api/v1/admin/stats/ and GET /api/v1/admin/users/search/ on your existing backend, and can permanently delete a user via DELETE /api/v1/admin/users/<id>/. Every deletion requires an explicit confirmation and cannot be undone. Nothing else here writes, modifies, or stores data server-side.
